Create event from a venue seat map

Create or select a venue once. Upload its visual seat map plus a seat-data file (CSV or JSON). TicketWAVES will import the sections, rows, seats and prices, so you do not have to type them into every event.

CSV columns: section,row,seat,price,currency,status. JSON should be an array of the same fields.
